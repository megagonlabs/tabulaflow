# Combine multiple sources

Join records from a local file and a database without changing either source.

**Sources:** your file and database

```text
Combine the account records in customers.csv with monthly revenue from the
warehouse and show revenue by customer segment.
```

TabulaFlow copies the relevant data into the workspace, joins it, and presents
the grouped result.
