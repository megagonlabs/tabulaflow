# Build a dataset from the web

Collect records from public pages and normalize them into a reusable table.

**Source:** a public website

```text
Build a table of the speakers on this conference website with their name,
organization, role, and profile URL. Normalize organization names.
```

TabulaFlow browses the pages in parallel, extracts the records, normalizes
organization names, and saves the result in the workspace.
