# Use the TabulaFlow app

The TabulaFlow app is an interactive data agent for analyzing, visualizing, and
transforming data through natural language. It can work across databases,
files, public datasets, documents, and the web while keeping source data
read-only.

Install the app, configure a model provider, and launch it:

```bash
uv tool install tabulaflow
export OPENAI_API_KEY="your-api-key"
tabulaflow
```

See [Models and providers](../models.md) for other providers, then learn how to
[connect your data](connecting-data.md) and adjust the app's
[configuration](configuration.md).
